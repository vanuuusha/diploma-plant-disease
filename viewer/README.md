# Diplom Viewer

Локальный веб-просмотрщик для `диплом_ред_с_приложениями.docx` на базе [SuperDoc](https://superdoc.dev) — рендер близкий к Microsoft Word, режим только-чтение.

## Запуск

```bash
cd viewer
npm install
npm run dev
```

Открыть http://127.0.0.1:5173

## Как это работает

- `public/diplom.docx` — симлинк на `../диплом_ред_с_приложениями.docx` (создаётся вручную, см. ниже).
- При изменении исходного `.docx` Vite ловит событие через `chokidar` и шлёт `full-reload` в браузер — открытая вкладка обновится автоматически.
- SuperDoc подгружает файл с cache-busting query (`?v=<timestamp>`) при каждом маунте, поэтому браузер не отдаёт устаревшую версию из кэша.
- `documentMode="viewing"` — read-only, никаких случайных правок и пересохранений.

## Симлинк

Если симлинка нет, его нужно создать один раз:

```bash
cd viewer/public
ln -sf "../../диплом_ред_с_приложениями.docx" diplom.docx
```

## Если поменялось имя/путь исходного docx

В `vite.config.js` поправить константу `docxSource`, в `public/` пересоздать симлинк.
